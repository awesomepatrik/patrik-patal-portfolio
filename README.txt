PATRIK PATAL PORTFOLIO
======================

Preview:
- Open index.html in any modern browser.

Deploy:
- Upload index.html to any static hosting provider (GitHub Pages, Netlify, Vercel static site, or your own web server).
- No build step or dependencies required.

Before publishing:
- Confirm the descriptions and dates for HLCA, Kredo.jp, Tachines, Lastbilbasen.dk, REMS SG, Cotople, and EPD Land.
- Add your preferred public email address and optional GitHub link.
- Add screenshots/project links where you have permission to share them.
- Confirm whether the CRM dashboard and workflow automation entries are suitable for public display.
- Consider adding a downloadable resume link.

This version is a responsive static HTML portfolio; it does not include a backend contact form.
